✨ Características Principales
🎯 Gameplay Innovador
Sistema de piezas de 2 bloques con combinaciones de colores

Modo VS para 2 jugadores en pantalla dividida

Sistema de ataques - Usa cargas para enviar piezas al oponente

Fase de setup inicial - Coloca 10 piezas antes del juego principal

Objetivo único: Elimina tus 10 piezas iniciales antes que tu oponente

🎨 Sistema Visual Avanzado
Fondos retro aleatorios (Pac-Man, Galaga, Top Gear)

Efectos de pantalla (Screen Shake en victorias y game over)

Animaciones de spawn para nuevas piezas

Interfaz intuitiva con preview de próximas piezas

Barras de ataque animadas que muestran cargas disponibles

🔊 Experiencia Sonora Inmersiva
Bandas sonoras retro con 5 pistas diferentes

Efectos de sonido para cada acción del juego

Sistema DJ inteligente que evita repeticiones consecutivas

Sonidos específicos por jugador (player_1, player_2)

👥 Sistema de Perfiles
7 perfiles personalizables con estadísticas completas

Museo de perfiles para editar nombres y ver stats

Seguimiento de records: Victorias, derrotas, puntuación máxima

Historial de enfrentamientos entre perfiles

Selección automática de últimos perfiles usados

🎯 Controles
Jugador 1 (Lado Izquierdo)
←/→: Mover izquierda/derecha

Rotate: Rotar pieza (funciona como arriba en menús)

Down: Bajar pieza rápidamente

Enter/Accept: Aceptar/confirmar

Attack Left/Right: Lanzar ataques

Back: Volver/cancelar (mantener 3 segundos en perfiles)

Jugador 2 (Lado Derecho)
Controles espejo con prefijo p2_

🏆 Sistema de Puntuación
Matches: 25 puntos por bloque eliminado

Cargas: 150 puntos por carga ganada

Máximo: 5 cargas simultáneas

Victoria: Eliminar 10 piezas iniciales primero

🛠️ Tecnología
Motor: Godot 4.5

Lenguaje: GDScript

Gráficos: Sprites personalizados

Audio: Sistema DJ con autoload

Persistencia: Sistema de archivos para perfiles

bash
